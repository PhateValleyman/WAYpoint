# WAYpoint project guidance

- This is a Minecraft Bedrock add-on targeting engine 1.21.100 and Script API 2.0.0.
- After every change run `make check` and `make addon`.
- Deliver `dist/WAYpoint_BP.mcpack`, `dist/WAYpoint_RP.mcpack` and `dist/WAYpoint.mcaddon` in a GitHub Release.
- Structure instances are persisted under the `voxen:structures` world dynamic property; control stones are generated by the structure system and are not manually placeable.
